      Payment by hand: your TWINT number

      Without Payrexx (see below), buyers pay to this number on the cart page and then say "I have paid": you check your TWINT app and confirm each payment yourself. On the payment step they see this number, the amount and their order number as the message. The number is only shown to someone who has started an order.

      Payrexx is connected, so this number is not used at the moment.

      Stock is changed under Inventory.

      Automatic TWINT payments (Payrexx)

      With a Payrexx account connected, every order gets its own TWINT payment page with a QR code for exactly its amount. Payrexx tells the shop when the money has arrived, and only then is the order complete — nobody can order without paying, and you have nothing to check. An order that is not paid in time cancels itself.

      Recommended once the site is on the internet: in Payrexx under Webhooks, add this address for the event "Transaction". Payrexx then tells the shop about a payment at once. Without it the shop asks Payrexx itself every few seconds, which works too:

      In your Payrexx account, TWINT must be switched on as a payment method. Refunds are made in Payrexx. The API key is kept on the server only and is not part of the backup file.

      TWINT QR code (optional)

      Payrexx is connected and makes a QR code for every order, so this picture is not used at the moment.

      With a QR code, buyers on a computer scan it with their TWINT app instead of typing your number. Save your code as a picture in the TWINT app and upload it here. The site cannot make this code itself — only TWINT can. Pay yourself a small amount with a second phone once, to be sure the code works.

      Sign-in code by email

      With this on, the password alone is not enough on a new device or a new internet connection: the server emails a 6-digit code that has to be typed in as well. A device you have confirmed is not asked again while it stays on the same connection.

      The app password is not the normal Gmail password. Make one in the Google account of that address: Security → 2-Step Verification → App passwords. The server uses it to send the code through Gmail itself; it is kept on the server only and is not part of the backup file.
